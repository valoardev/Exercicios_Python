# Lista de Exercícios de Lógica de Programação em Python

Este repositório contém uma coleção de exercícios de **Lógica de Programação em Python**, organizados em três partes progressivas, com foco no aprendizado de estruturas condicionais e operadores básicos da linguagem.

O objetivo é desenvolver o raciocínio lógico, praticar resolução de problemas e consolidar os conceitos fundamentais da programação utilizando **Python**.

## Estrutura do Repositório

Os exercícios estão organizados em **3 partes**, seguindo uma progressão de dificuldade:

### Parte 1 — Estruturas `if` e Operações Básicas
Nesta etapa, os exercícios utilizam apenas:

- Estrutura condicional `if`
- Operações matemáticas básicas
- Comparações lógicas simples

**Conteúdo abordado:**
- Operadores aritméticos
- Comparações numéricas
- Validações simples
- Tomada de decisão básica

### Parte 2 — Estruturas `if` e `else`
Nesta etapa, são introduzidas decisões com dois caminhos possíveis utilizando:

- `if`
- `else`

**Conteúdo abordado:**
- Condições verdadeiras e falsas
- Estruturas de decisão binária
- Tratamento de diferentes cenários

### Parte 3 — Estruturas `if`, `else` e `elif`
Na etapa final, os exercícios trabalham decisões mais complexas utilizando:

- `if`
- `elif`
- `else`

**Conteúdo abordado:**
- Múltiplas condições
- Estruturas condicionais encadeadas
- Resolução de problemas com diferentes possibilidades

## Tecnologias Utilizadas

- Python 3

## Objetivo

Este material foi desenvolvido com fins de estudo e prática da lógica de programação, sendo indicado para iniciantes que desejam fortalecer a base em programação utilizando Python.
