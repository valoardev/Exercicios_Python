# 🐍 Lógica de Programação em Python

Repositório destinado ao armazenamento de exercícios de **lógica de programação utilizando Python**.

Os exercícios foram organizados em listas conforme os principais conceitos estudados, seguindo uma evolução gradual de dificuldade. Cada lista possui diferentes partes, onde os exercícios aumentam sua complexidade conforme novos conceitos são introduzidos.

---

## 🎯 Objetivo

Este repositório tem como objetivo desenvolver e praticar:

- 🧠 Raciocínio lógico e resolução de problemas;
- 🔀 Estruturas condicionais;
- 🔄 Estruturas de repetição;
- 📦 Organização e reutilização de código;
- 🐍 Fundamentos da linguagem Python.

---

## 🛠️ Tecnologias utilizadas

- Python 3

---

# 📂 Estrutura do Repositório

# 📈 Evolução dos Estudos

A sequência das listas representa a evolução dos conceitos:

```
Condicionais
     ↓
While
     ↓
For e Range
     ↓
Funções
```

Cada etapa adiciona novas ferramentas para criação de programas mais organizados e completos.

---

# 📚 Sobre os Exercícios

Cada parte contém uma sequência de exercícios práticos, normalmente entre **5 e 10 exercícios**, organizados do nível introdutório até desafios mais complexos.

A divisão permite acompanhar a evolução do aprendizado, começando com problemas simples e avançando para aplicações que combinam diferentes conceitos de programação.
